# SkipIntro

*[Versão em português](README.md) · [All mods](../../README.en.md)*

Opens the game straight to the main menu, without the Eek! Games video and
the disclaimer screen. The menu shows up in about 1.5 seconds.

- Both screens already move on when you press a key; the mod does that for
  you, and the game itself loads the next screen.
- The credits and the game's other screens aren't affected.
- If something fails, the mod logs it once and the screens show up as usual.

The mod doesn't change any game file or save and has no settings.

## Compatibility

Last tested on House Party 1.5.2.14289 with MelonLoader 0.7.3. See the
details in the [main README](../../README.en.md#compatibility).

## Installation

1. Install MelonLoader as described in the [main README](../../README.en.md#installation).
2. Download `SkipIntro.dll` from the
   [Releases](../../../../releases?q=SkipIntro&expanded=true) page and put it
   in the `Mods` folder at the game root.
3. Start the game.

To uninstall, delete `Mods\SkipIntro.dll`.
