# AutoContinue

*[Versão em português](README.md) · [All mods](../../README.en.md)*

When you load a save or start a new game, moves on from the first loading
screen to the second by itself, without waiting for a click.

- The first screen finishes loading and shows the click prompt; the mod
  clicks for you at that moment, and the game itself moves on to the next
  screen.
- Loading takes the same time; it just doesn't sit there waiting.
- If something fails, the mod logs it once and the screen waits for the
  click again.

The mod doesn't change any game file or save and has no settings.

## Compatibility

Last tested on House Party 1.5.2.14289 with MelonLoader 0.7.3. See the
details in the [main README](../../README.en.md#compatibility).

## Installation

1. Install MelonLoader as described in the [main README](../../README.en.md#installation).
2. Download [`AutoContinue.dll`](../../dist/1.0.0/AutoContinue.dll) (download button on the
   file page) and put it in the `Mods` folder at the game root.
3. Start the game and load a save.

To uninstall, delete `Mods\AutoContinue.dll`.
